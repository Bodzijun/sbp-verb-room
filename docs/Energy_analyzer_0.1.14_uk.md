# Verb Room 0.1.14: карта звукової енергії

Вкладка **Energy** показує розрахункове покриття залу на горизонтальному зрізі. Аналіз запускається вручну кнопкою **Analyze**, працює у фоні й не змінює звук, маршрутизацію або сцену. **Cancel** зупиняє поточний розрахунок, зберігаючи попередню карту. Закриття редактора також скасовує його завдання; карта не зберігається у пресеті.

## Керування

- **Excitation**: усі чутні джерела або одна група. Застосовуються поточні позиції, напрямки, підсилення, Solo/Mute, розкладка й вільні точки каналів. LFE не входить до просторової карти.
- **Octave band**: 125–8000 Гц або Broadband — середня енергія семи смуг з однаковим збудженням.
- **Probe height**: абсолютна висота зрізу над базовою підлогою, 0.1–30 м. Клітинки під піднятою підлогою або над закритою основною стелею виключаються.
- **Direct / Early / Tail**: компоненти для аналізу. Direct включає проходження й дифракцію за моделлю рушія; Early — відбиття першого порядку з поточним рівнем Early; Tail — пізнє поле з поточним рівнем Tail. Для нового вибору натисніть Analyze.
- **Total tail rays**: 12k / 48k / 192k променів загалом, розподілених між просторовими точками вибраних джерел. Для великого оркестру або нерівної карти використовуйте більший бюджет. За вимкненого Tail промені не трасуються.
- **Map resolution**: 16 / 24 / 32 клітинки вздовж довшої сторони сцени; з 0.1.15 також 48 / 64 / 96. Друга сторона зберігає пропорції в метрах. Базове значення — 24. Більша сітка збільшує час аналізу та використання пам'яті лише для карти; аудіорушій не змінюється. Для більшості перевірок достатньо 48–64, а 96 зручно для докладного перегляду. Деталізація хвоста також обмежена приймальними сферами трасувальника та бюджетом променів.
- **Tail integration**: тривалість накопичення енергії хвоста, до 20 с. Скорочення горизонту виключає пізніші приходи з аналізу й не змінює аудіохвіст.
- **Colour range**: діапазон кольорів нижче піка карти; з 0.1.15 — 0.5–120 дБ (раніше 20–80). Менше значення підсилює контраст невеликих відмінностей; для рівномірного хвоста спробуйте 1–5 дБ. **Auto** підбирає шкалу від піка до п'ятого процентиля енергії освітлених клітинок поточної смуги, охоплюючи приблизно 95% їхніх значень. Це змінює лише відображення. Смугу й діапазон можна змінювати без повторного трасування.

Рожевий маркер — поточні X/Y слухача; висоту зрізу задає Probe height. Наведення показує координати клітинки та рівень відносно піка. Межі карти задає прямокутник стін, а для сцени без стін — область навколо джерел. Осі карти: +X праворуч, +Y вгору; її орієнтація не залежить від повороту редактора чи слухача.

## Як читати результат

0 дБ на кольоровій шкалі відповідає найенергійнішій клітинці поточної смуги. Під картою виводиться також її пік відносно одиничного джерела на 1 м. Це модельний опорний рівень, без калібрування у dB SPL. При порівнянні різних смуг/карт враховуйте числовий пік: кожна кольорова шкала нормалізується окремо.

Збудження — одиничний сигнал у кожній просторовій точці; енергії незалежних шляхів і джерел додаються. Для сумованої групи аналізується її одна просторова точка. Поточна музика, кореляція каналів і спектр семплів не вимірюються. Карта використовує омніприймачі й не залежить від вихідного мікрофонного масиву, Dry/Wet, загального Output gain чи Solo компонентів аудіотракту. Вибір Direct/Early/Tail на вкладці Energy керує лише аналізом.

Аналіз використовує фактичну геометрію рушія, включно зі згенерованим clutter і варіаціями roughness. Приховані в редакторі поверхні залишаються акустично активними. Раннє поле обмежене горизонтом затримки рушія (0.75 с); пізня енергія накопичується трасуванням без екстраполяції гістограми. Хвіст є просторовою оцінкою за приймальними сферами трасувальника, тому дрібні клітинки не означають таку саму фізичну роздільну здатність хвоста.

Карта описує геометричну акустичну модель, без хвильових мод та інтерференційних провалів. Для прослуховування результату й остаточної оцінки хвоста використовуйте аудіовихід плагіна.

Після змін джерел, матеріалів або налаштувань аналізу з'являється **OUTDATED**: видимою залишається попередня карта. Натисніть Analyze, щоб оновити її. Переміщення слухача лише пересуває маркер, бо карта вже містить фіксовані просторові проби.

Пізнє дифузне поле може бути майже рівномірним. На широкій шкалі воно матиме близькі помаранчево-червоні кольори. Вузька шкала допомагає побачити відмінності, але також підсилює випадкову плямистість від обмеженого числа променів. Збільште Total tail rays і повторіть аналіз, щоб оцінити стабільність фактури; стежте за числовими значеннями дБ на шкалі та при наведенні.
