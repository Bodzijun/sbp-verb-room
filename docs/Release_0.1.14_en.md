# Verb Room 0.1.14

- Added an **Energy** tab with a background sound-energy coverage map of the room.
- Analyze all audible sources or one source group at a chosen height, with Direct / Early / Tail selection, seven octave bands and a broadband view.
- Adjustable ray budget, grid resolution, integration time and colour range; progress and Cancel support.
- Uses live source poses, gain, Solo/Mute and free channel points, plus the engine's actual geometry and materials. Hover for values; the listener is marked on the map.
- Source/scene changes mark an existing map as outdated. Analysis leaves audio processing and routing unchanged.

The map predicts time-integrated energy for unit excitation with omnidirectional probes. See the [analyzer guide](Energy_analyzer_0.1.14_en.md) for interpretation and limits. Existing preset and project formats remain compatible.

Also includes the 0.1.13 fixes for Outliner spacing in Mix/Decay and toolbar spacing.
