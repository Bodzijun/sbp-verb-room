# Рішення власника щодо нового інтерфейсу (WebView)

Прийнято 2026-11-10 у відповідь на розділ 9 [плану перенесення](WebView_UI_plan_uk.md). Ці рішення мають пріоритет над рекомендаціями плану, якщо вони розходяться.

| № | Питання | Рішення |
|---|---|---|
| 1 | Linux зберігає старий (native) редактор? | **Так.** Native — основний і запасний; WebView на Linux лише як експериментальна опція. |
| 2 | Чи всі функції з позначкою NEW мають запрацювати разом із новим інтерфейсом? | **Ні.** Спершу паритет із наявним рушієм. Недоступні функції **не приховувати, а показувати з позначкою «недоступно»**. |
| 3 | Size — автоматизована ручка? | Спочатку разова команда Scale room; безперервний автоматизований Size — пізніше, окремою специфікацією. |
| 4 | Кількість каналів Ring незалежна від хоста? | У першому релізі показувати фактичну кількість від хоста. |
| 5 | A/B зберігається в проєкті? | Спочатку лише в межах сесії. |
| 6 | Розмір вікна | 1280×800 за замовчуванням; мінімум 900×600, як зараз. |
| 7 | Кольори матеріалів у пресетах | На розсуд виконавця («як краще і зрозуміліше»). Обрано: спочатку локальні налаштування користувача, формат `.txt` / `.verbroom` не змінюється. Перенесення кольорів між користувачами — окремий сумісний пакет формату пізніше. |
