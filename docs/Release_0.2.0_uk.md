# Verb Room 0.2.0

Фізично обґрунтований кімнатний реверб (VST3). Ви малюєте кімнату, ставите джерела звуку й слухача, а плагін моделює,
як ця кімната звучить у цій точці. Пакети: Windows (x64), macOS (universal) і Linux (лише класичний інтерфейс).

**Статус.** Новий інтерфейс на macOS — перший випуск: зібраний, але ще мало перевірений на реальних Mac і хостах.
У разі проблем перемкніться на класичний інтерфейс.

## Нове порівняно з 0.1.16

- **Новий інтерфейс:** вікно зі змінним розміром, 3D-в'юпорт, сторінки Main та **Edit room** (стіни, зони підлоги й
  стелі, пластини, каталог матеріалів, розміри й масштаб), outliner, inspector, індикатор навантаження CPU, криві
  згасання по смугах, карта енергії, шляхи відбиттів. Undo/redo (Ctrl+Z / Ctrl+Y у Windows, Cmd+Z / Cmd+Shift+Z на macOS).
- **Physical / Creative:** у Creative доступні Size, Pre-delay, Stereo width, Ducking і Freeze, що справді тримає хвіст.
  Шкала поглинання та помічник цільового RT60.
- **Шляхи руху:** джерела й слухач рухаються по шляхах; **таймінг** (Start %, End %, Time % на точку, easing);
  **орієнтація** Manual / Along path / Look at (також між учасниками однієї групи); **групи та зв'язування**;
  панель **Timeline**; **Bake path** — фонове обчислення пізнього хвоста вздовж шляху (кілька незалежних джерел,
  зв'язані групи, записаний прохід слухача).
- **Keep processing during silence** (Settings): автоматизація позиції працює й у тиші. Вимкнено за замовчуванням,
  більше навантажує CPU.
- **AmbiX 1-го, 2-го та 3-го порядку** (4, 9 і 16 каналів, ACN/SN3D) у кінці списку форматів слухача.
- **Профілі спрямованості:** тека `Profiles` за замовчуванням, запам'ятовується остання тека; **Profile aim**.
- Профілі спрямованості діють на прямий звук і ранні відбиття. Для пізнього хвоста джерело вважається всеспрямованим.
- **Рушій:** закрита кімната справді закрита (без витоку крізь кути й стіни), правильний рівень хвоста біля стін,
  обмежена вартість пошуку дифракції, плавніший хвіст, вимірювачі виходу після фінального підсилення.

Старі `.verbroom`, `.txt` і проєкти завантажуються як раніше.

## Встановлення

- **Windows:** скопіюйте папку `Verb Room.vst3` до `C:\Program Files\Common Files\VST3\`. Новому інтерфейсу потрібен
  WebView2 Runtime (зазвичай є у Windows 10/11); без нього плагін сам відкриє класичний інтерфейс.
- **macOS:** скопіюйте `Verb Room.vst3` до `/Library/Audio/Plug-Ins/VST3/` або `~/Library/Audio/Plug-Ins/VST3/`.
  Пакет підписаний ad-hoc, не нотаризований. Дозвольте його правою кнопкою → **Open** або командою
  `xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/Verb Room.vst3"`.

## Перемикання інтерфейсу

- Новий → класичний: меню **Theme** → **Classic UI** (вибір запам'ятовується).
- Класичний → новий: кнопка **New UI** у класичному вікні.
- Змінна середовища `VERB_UI=classic` або `VERB_UI=web`. За замовчуванням і на Windows, і на macOS відкривається новий
  інтерфейс (раніше зроблений вибір запам'ятовується); якщо він не стартує, відкривається класичний. Налаштування: `editor.ini` у `%LOCALAPPDATA%\SBP\VerbRoom`
  (Windows) або `~/Library/SBP/VerbRoom` (macOS).

## Відомі обмеження

- macOS: клавіші, які сторінка не використала, **не передаються хосту** (у Windows передаються).
- AmbiX у REAPER потребує парної кількості каналів треку.
- Для автоматизації в тиші в REAPER увімкніть Keep processing або *Compatibility settings > Ignore plug-in reported
  tail size*.
- Геометрія 2.5D, без низькочастотних мод кімнати, хвіст — статистична оцінка; великі сцени навантажують CPU.
- Дуже великі зали з Ambisonics 3-го порядку (16 каналів) можуть перевантажити CPU у режимі Creative навіть із нейтральними
  макросами; для таких сесій використовуйте режим Physical (Physical програв пресет оркестру без пропусків).
